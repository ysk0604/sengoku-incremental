# 画像一覧

`assets/img/` に、下の表のファイル名で WebP 画像を置くと、ゲームの表示が自動で切り替わります。
置いていない画像は、今の仮の表示（色の箱と文字・図形）のまま動きます。1枚ずつ置いても大丈夫です。

## 共通のきまり

- 形式：**WebP**（拡張子は `.webp`、ファイル名は半角小文字）。画質の目安 80
- 大きさ：表の「大きさ」のピクセル数で作る。縦横の比率が同じなら、多少大きく・小さくても表示は崩れない
- **透過**と書いた画像は、背景を透明にする（それ以外は透明にしない）
- ファイルの重さの目安（低スペックPCのため）：一枚絵・地図・背景は 1枚 300KB 以下、そのほかは 1枚 50KB 以下
- 画像は、その画面を初めて開いたときに読み込む（起動時にまとめて読み込まない）
- スマホの縦画面（幅360〜430px）でも使えるように、表示する大きさの約2倍で作ってある。一枚絵は、スマホでは左右が少し切れることがあるので、**大事なものは真ん中に描く**
- 画風の想定：厚塗りの武将イラスト、水墨画風の背景（仕様書7章）

全部で **72枚** です。

**道具の絵の置き方（9枚とも同じ）**

```
(0,0) ┌──────────────┐
      │  刃            │   刃（ツルハシの頭）は左上
      │   ●(40,40)     │   ● = カーソルの位置に重なる点（刃の真ん中）
      │      ＼         │
      │        ＼柄     │   柄は左上から右下へ斜めに
      │          ＼     │
      │      (104,116)◎│   ◎ = 柄の握り（振るときの回転の中心）
      └──────────────┘(128,128)
```

- 画面には 64×64 の大きさで出す。素材の色の違いが小さくても分かるように、刃ははっきりした色で描く
- 天下の道具は、ゲーム側でも淡い金色の光を重ねる
- 画像がない間は、上と同じ色分けの簡単な図形（仮の絵）で描いている
